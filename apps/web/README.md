# CasePilot Web

CasePilot 的 React 19 + TypeScript Web 界面，使用 vinext/Vite 运行。

## 前置条件

- Node.js `>=22.13`
- pnpm `11.9`
- CasePilot API 默认运行在 http://localhost:8000

## 本地启动

```bash
corepack enable
pnpm install --frozen-lockfile
pnpm dev
```

默认访问地址为 http://localhost:3000。

## 常用命令

```bash
pnpm dev
pnpm lint
pnpm test
pnpm build
```

完整部署、后端启动和验收说明见仓库根目录的
[README](../../README.md)。
