# Inspect and reuse

Use this capability when the current goal calls for finding or reusing existing cases. It is optional before planning and is not required before direct rewriting.

Inspect authoritative selection and collection first. Literal title search is not semantic search: inspect returned content for semantic choices, respect truncation, and never broaden an explicit no-match filter. Retain exact observed references and versions. Uploaded rows are evidence until preview_uploaded_cases materializes private candidates; select the returned candidate references before rewriting them.

A requested existing-only reuse uses prepare_reuse with strategy=select. Only when the user also requests uncovered cases may select_and_generate prepare the missing scope. Record all requested goals in the existing typed plan, distinguish proven coverage from uncertain similarity, and do not invent missing coverage. Read results, selection, and a prepared reuse proposal are different outcomes. Return actual current receipts. Reuse into a new destination retains its own human creation gate; never approve it or create a second standalone proposal to bypass it.

Distinguish the number of sources from the number of conflicting claims. Group agreeing statements and identify the exact contradictory proposition and its source locations. Multiple sources are not automatically multiple conflicts. Ask for authority only for genuine unresolved contradictions; do not infer authority from recency.
