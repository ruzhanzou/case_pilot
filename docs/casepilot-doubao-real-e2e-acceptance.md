## 本轮发现并修复

1. **P1：候选写入后用例管理显示旧数据。**
   写入接口已成功，但页面直接切换导致集合与用例状态未刷新。现在进入用例管理前会
   重新加载当前集合和正式用例。

2. **P1：脑图底部工具栏被裁切。**
   脑图高度原先没有扣除 58px 视图栏，900px 高度下控件落到画布外。现已按容器剩余
   高度布局，并在三个桌面宽度下复验通过。

3. **P1：执行页存在 10–13px 正文与按钮。**
   已统一执行工作区字号规则；工作区的优先级标签和脑图缩放值也已提升到 12px。

4. **P2：本地化覆盖矩阵字段触发错误质量告警。**
   真实模型返回“需求编号/测试点编号”时，校验器只识别英文键。现同时兼容标准键与
   本地化键，并新增回归测试。

5. **P2：知识源刷新成功后残留旧错误提示。**
   成功刷新时现在会清除历史错误状态。
