## 统一术语

- 用例集合和用例资产没有 QA 执行状态。
- 未执行、通过、不通过、跳过、堵塞只保存在独立执行任务中。
- 评审是 Review Event，发布状态属于 Revision/Baseline 生命周期。
- Candidate Revision 与 Published Revision 是版本生命周期，不作为用户可见状态列。
- 当前运行版本已启用 AI 工作台、异步生成任务、知识来源选择和真实模型候选生成；
  质量评分与需求覆盖仍需分层呈现，复杂文件解析与生产凭证治理属于后续服务端里程碑。
- 正常连接状态不常驻顶部；只有异常影响操作时才提示。

## 当前实现与路线图边界

- V1.0 已包含新对话、历史恢复、知识索引、阻塞澄清、结构化测试说明、
  分阶段候选生成、列表/脑图评审、正式集合交接和 QA 执行。
- 已包含 Generation Job API、Celery Agent、Mock/真实 Provider、混合知识检索
  与正式 Revision；外部连接器、自动化脚本与自动发布仍在路线图中。
- V0.x 验收文件仅保留历史证据；当前资产/执行状态边界以
  [V1.0 交互规格](./product-interaction-design.md) 和端到端测试为准。
