# 对话、脑图、Review 工作区真实联动验收

日期：2026-10-06

## 验收环境与范围

- 前端：`http://localhost:3105`；API：`http://localhost:8101`。
- 使用独立验收集合，正式用户的 1001 条用例集合未参与增删改。
- 通过浏览器输入自然语言、点击 Review 和脑图、确认或取消变更；使用真实 API 复核版本与内容，没有拦截或伪造业务响应。
- 查询和明确的标题修改可以走确定性处理；去重、质量检查、知识问答、测试说明与候选生成调用真实模型。
- 主验收集合：[真实联动验收](http://localhost:3105/workbench/collections/5dca4b4d-00bd-4658-8fe0-63b2cf272f0b)。初始 3 条；确认删除 1 条后 2 条；确认纳入 2 条候选后 4 条。

## 本轮修复

1. Review 面板切换到脑图时保留组件状态，返回后不会清空保留项、筛选和分页。
2. 自然语言解析出的目标同步到工作区选中项，并保存到会话上下文，防止刷新或后台更新恢复为旧目标。
3. 变更审阅显示业务用例编号，避免暴露内部 UUID 作为主要标识。
4. 完成、失败、取消的工作流不再被历史 active_job_id 误判为进行中。
5. 候选纳入正式集合后，后续操作使用正式用例 ID 和最新版本；生成结果摘要进入候选审阅，不再误指向测试说明。
6. 正式用例变更后，旧 Review 显示版本提示；不再一直显示“尚未开始”或把不存在的用例显示为内部 ID。

## 耗时与验收限制

- 真实生成阶段约 4 分 22 秒，触发模型超时和备用模型切换。测试说明阶段也经历备用模型切换。该耗时仍是体验上的限制。
- 主脚本原设 4 分钟候选等待超时；后台最终成功完成。随后从真实持久化的候选状态继续浏览器验收，确认纳入、脑图和刷新全部通过。脚本等待上限已调整为 10 分钟，并未用模拟结果替代。
- 本轮证明独立小集合的多意图联动与落库；未重新执行原始 1001 条集合的大规模模型生成，也未验证服务重启中的任务恢复。
- 修复前已经生成的候选快照报告可能仍保留历史候选编号；界面对不可定位引用提示重新检查，新生成的后续报告使用正式用例 ID。
- Review 的选择保留针对同一页面内的视图切换；刷新后尚未提交的保留项选择不属于本轮持久化承诺。
