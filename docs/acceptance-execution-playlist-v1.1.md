# CasePilot 执行 Playlist 验收

> 日期：2026-09-07
> 范围：可复用 Playlist、跨集合选例、用例搜索与 Playlist 执行任务

## 1. 从集合开始执行

1. 进入“用例集合”，选中一个非空集合并点击“开始执行”。
2. 首次进入时确认系统使用集合名称和集合全部用例初始化 Playlist。
3. 保存 Playlist，返回集合后再次点击“开始执行”。

通过标准：

- 首次进入无需手工重复填写 Playlist 名称。
- 再次进入会提供“复用已有 Playlist”和“按当前集合重新创建”。
- 重新创建的重名 Playlist 自动追加序号，不覆盖已有清单。

## 2. 多集合与自由选例

1. 新建或编辑 Playlist，在搜索区输入集合名称，依次完整加入两个匹配集合。
2. 收起、展开搜索结果中的一级集合，并在二级用例列表中勾选部分用例。
3. 在“已选择的用例”区域按集合检查已选清单，并取消一条已选用例。
4. 选择一条同时属于多个集合的用例。

通过标准：

- 不再单独展示集合选择区；已选清单按一级集合、二级用例组织并支持收起、展开。
- 搜索同时覆盖集合名称与用例字段；每个搜索结果集合支持“一键完整加入”，也支持展开后多选用例。
- 完整集合和逐条选择可以混合使用。
- 相同 `test_case_id` 只出现一次，并显示自动去重数量。
- 保存后用例顺序稳定，集合后续新增用例不会自动进入 Playlist。

## 3. 空间级搜索

分别输入用例编号、标题关键字、模块和标签进行搜索。

通过标准：

- 搜索覆盖当前空间全部有效用例。
- 搜索结果按一级用例集合、二级用例分组展示，并包含编号、标题、模块和标签。
- 无匹配项时显示明确空状态，已选用例不因搜索条件变化而丢失。

## 4. 创建与执行任务

选择保存后的 Playlist，填写任务描述和执行人并创建任务。

通过标准：

- 任务只包含 Playlist 中的去重用例，并冻结创建时的当前 Revision。
- 任务历史和详情显示 Playlist 名称、“来自 N 个集合”和用例总数。
- Playlist 后续修改或删除不改变已有任务。
- Playlist 包含已删除或无当前 Revision 的用例时阻止创建，并要求先移除。
- 执行人分配、进度同步、并发保护和结束任务行为与原流程一致。

## 5. 向后兼容

- 升级后原集合任务仍可读取，并继续显示原集合名称。
- 原集合级执行任务 API 保持可用。
- Playlist 和用例搜索均严格按空间隔离。
