# 工作台用户视角目标审计

目标：用户通过自然语言完成用例相关操作，避免意图误判及状态混乱。上一阶段已完成修改草稿重构，本轮属于实质进展，不代表整个目标完成。

## 本轮改进

普通消息路由的 active_operations 原先只有 id、类型、状态、目标和结果，缺少当前草稿要求及未解决问题。新增有长度上限的 routing_draft_context，提供原始要求、当前范围、修改要求、澄清问题和预览状态；排除用例正文、附件正文以及任意 payload 字段。路由提示明确这些是数据，并区分短回复续接与独立新任务。

## 明确编号完整性修复

对用例/候选/编号/case id 明确标记的字母开头、含连字符或下划线编号，增加模型选择前的精确存在性校验。多编号中任一不存在时整次澄清；不允许模型省略未知编号后继续处理其余目标。字段赋值和字段内容查询中的编号不当作目标；明确“不是用例 X，而是用例 Y”的撤回在累积补充历史中也有效。
