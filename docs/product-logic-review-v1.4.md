# CasePilot 产品逻辑 Review V2.1

> 文档版本：V2.1
> 日期：2026-07-27
> 范围：当前 `apps/web`、`apps/api`、Figma 脑图/测试执行 V4、产品规格和交互文档
> 结论：用例资产、脑图和空间级执行任务的数据闭环通过；真实 AI Provider、文件解析和评审发布仍按路线图推进。

## 1. 已统一的关键决策

| 主题 | 统一结论 | 当前实现 |
|---|---|---|
| 产品入口 | 当前自部署验收先登录本地账号 | 登录后进入默认质量空间 |
| 资产边界 | 空间 → 用例集合 → 用例 → Revision | 集合、用例和 Revision 写入 PostgreSQL |
| AI 路线图 | AI 只生成 Candidate Revision | 独立 Agent/Mock Provider 已隔离；当前产品不开放模型选择、生成和 AI 改写入口 |
| 资产状态 | 集合和用例无 QA 执行状态 | 资产页与脑图不展示结果下拉或结果图例 |
| 评审 | 评审使用 Review Event | 通过/驳回不复用 QA 结果；当前尚未启用评审发布 |
| 多视图 | 脑图、列表和详情读取同一 Revision | 当前由同一持久化用例数据驱动 |
| 服务健康 | 正常状态不常驻顶部 | 仅异常影响操作时提示 |
| 脑图操作 | 滑动平移与缩放分离，复杂树可全屏 | 全屏、`Esc` 退出、折叠、叶子隐藏和共同前置条件投影 |
| 测试执行 | 每次运行只填写任务描述 | 空间级历史、独立 Run/Record、冻结 Revision、多人进度和并发保护 |

## 2. 端到端逻辑检查

### 2.1 登录与空间

`登录 → 获取账号与空间 → 进入默认空间 → 刷新空间资产`

- 当前登录、会话保持和默认空间可验收。
- 用例集合、用例、Revision、执行任务和执行记录均按 `space_id` 隔离并持久化。
- 成员邀请和角色管理仍属于后续范围。

### 2.2 用例资产创建与维护

`选择集合 → 新建/编辑结构化用例 → 校验字段 → 创建不可变 Revision → 列表/脑图/详情同步`

- 集合和用例 CRUD 已接入正式 REST API 与 PostgreSQL。
- 编辑保存创建新 Revision，不覆盖历史内容。
- AI 生成、文件解析、模型选择、取消和断点续作当前未启用。

### 2.3 脑图与详情

`选择脑图 → 滑动平移/独立缩放 → 折叠或隐藏叶子 → 全屏查看 → 选择节点 → 查看或编辑 Revision`

- 资产页、脑图和详情不显示 QA 执行结果。
- 共同前置条件是视图投影，不修改 Revision 中的原始前置条件。
- 原生全屏不可用时降级为页面内全屏，退出后恢复原布局。

### 2.4 评审与发布

`Candidate Revision → Review Event → Published Baseline`

- 当前运行版本不提供评审发布入口。
- 后续需要独立评审面板、Reviewer 权限、批量影响预览和发布门禁。

### 2.5 测试说明

`同一结构化数据 → 脑图 / 列表 / 详情 / 测试说明 → 导出`

- 当前列表、脑图和详情共享持久化用例及 Revision。
- 测试说明、Markdown/JSON、DOCX、PDF、XLSX 导出和 Baseline 发布均未启用。

## 3. 执行任务结果规范

| 中文 | API 值 | 颜色 | 允许来源 | 典型后续 |
|---|---|---|---|---|
| 未执行 | `not_run` | 灰 | 新建 Run | 执行当前用例 |
| 通过 | `passed` | 绿 | 当前 Run | 保留结果 |
| 不通过 | `failed` | 红 | 当前 Run | 记录实际结果/缺陷 |
| 跳过 | `skipped` | 紫 | 当前 Run | 记录本轮原因 |
| 堵塞 | `blocked` | 橙 | 当前 Run | 记录依赖和解除条件 |

状态不能只靠颜色识别；执行任务视图必须同时显示文字和状态图标。资产列表、脑图和资产详情不得显示最近一次运行结果。

执行结果必须关联 Run、任务描述和冻结的 Case Revision。同一集合可创建多个任务，每个任务独立计算进度和结果。

## 4. AI 路线图边界

- `auto`、`pro`、`local` 等模型路由属于后续 Provider Adapter 设计，不在当前运行界面暴露。
- 后续 Generation Job 必须保存 `model_id`、Provider、模型版本、参数、提示词版本和输入来源快照。
- 本地模型不可用时必须阻止提交或要求用户切换，不能静默改用云模型。
- AI 只能创建 Candidate Revision，不能直接发布 Baseline 或写入 QA 执行结果。

## 5. 当前剩余风险

| 优先级 | 风险 | 处理基线 |
|---|---|---|
| P0 | 当前分支尚未接入自动化 CI 和迁移 smoke | 发布基线补充 GitHub Actions |
| P1 | 评审发布、Reviewer 权限和 Baseline 尚未实现 | 后续评审里程碑 |
| P1 | AI Provider、文件上传和解析未启用 | Provider Adapter 与对象存储里程碑 |
| P1 | 执行任务缺少筛选、成员分工和报告 | QA 执行后续迭代 |
| P2 | 脑图节点位置尚未跨会话持久化 | 视图偏好存储 |

## 6. 本轮验收结论

- UI 标注问题已纳入实现、Figma 和验收文档。
- 产品、交互、API 命名和资产/执行状态语义已经对齐。
- 当前可继续验收真实用例资产、脑图和执行任务闭环。
- AI、解析、评审与发布不得以当前界面设计替代，仍按后续里程碑推进。

- Web ESLint、生产构建和渲染测试通过。
- API 测试通过。
- 脑图滑动平移不改变缩放比例，支持节点折叠、叶子隐藏、共同前置条件投影和全屏查看。
- 任务创建按钮保持可点击；描述为空时显示字段级错误并自动聚焦。
- 资产详情、列表与脑图不展示 QA 结果；执行页按 Run 标记五种结果。
- 空间级任务历史、多人进度和乐观并发控制已接入 PostgreSQL。

- 本地模型能力探测、不可用阻断和真实 Provider 路由未实现。
- 文件对象存储、解析、OCR、真实上传进度和断点续作未实现。
- DOCX、PDF、XLSX 发布导出与版本签名未实现。
- 执行任务筛选、成员分工、报告和步骤级审计尚未实现。
