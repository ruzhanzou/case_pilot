## 1. 核心用户动线

```mermaid
flowchart LR
  A[登录质量空间] --> B[进入 AI 用例工作台]
  B --> C[选择目标用例集与生成模型]
  C --> D[输入测试目标]
  D --> E[Agent 分阶段生成候选用例]
  E --> F[在脑图或列表中评审]
  F --> G[查看用例详情与覆盖提醒]
  G --> H{是否确认写入}
  H -- 否 --> I[继续改写、排除或重新生成]
  I --> F
  H -- 是 --> J[写入正式用例资产]
  J --> K[进入用例管理]
  K --> L[按集合、编号、模块或标签检索]
  L --> M[查看结构化用例详情]
  M --> N[编辑并保存为新 Revision]
  N --> O[列表与脑图同步展示最新版本]
  O --> P[进入 QA 执行任务]
```
