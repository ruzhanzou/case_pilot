# 登录与简单用例生成验收 V0.1

## 目标

本阶段只验收一条最小业务闭环：

```text
创建或登录本地账号
→ 自动进入默认质量空间
→ 输入简单测试需求
→ 本地 Redis/Celery 执行 Mock 生成任务
→ 前端显示阶段进度
→ 返回风险与结构化 Pending 用例
```

## 本地组件

| 组件 | 本地职责 |
|---|---|
| Web | 登录、需求输入、进度和用例结果 |
| FastAPI | 会话、权限、任务创建与 SSE |
| PostgreSQL | 账号、会话、空间、集合和生成任务 |
| Redis | Celery Broker、结果存储和生成进度事件 |
| Celery Worker | 执行 Mock AI 生成管线 |

所有组件通过 `compose.yaml` 在本机运行，不依赖云数据库或云消息队列。

## 验收示例

输入：

> 请为手机号验证码登录生成测试用例，覆盖验证码错误、过期和重复提交。

预期：

1. 页面展示文件解析、需求规范化、风险识别、测试点生成、用例生成、质量检查和测试说明阶段。
2. 进度由本地 Worker 通过 Redis 推送，不使用浏览器计时器伪造。
3. 至少返回一条结构化用例，包含用例名称、前置条件、执行步骤和校验点。
4. 新生成用例状态固定为 `pending`。
5. 刷新页面后账号会话仍有效。
6. 首页选择模型后，进入用例集工作台仍保持同一选择。
7. 用例列表的 Pending、通过、不通过、跳过、堵塞具有不同文字和颜色语义。
8. 脑图工具栏、图例、对话发送按钮和提交评审按钮与窗口底部保持安全间距。

## 本阶段不验收

- 真实大模型调用。
- Word/PDF/Excel 真实解析。
- 脑图节点持久化编辑。
- 邮箱验证码投递。
- MCP、本地 Coding Agent 和自动化执行。

这些能力继续按开发基线后续里程碑推进。
