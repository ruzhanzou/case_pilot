# ADR-0001：本地验收采用登录优先

- 状态：临时接受
- 日期：2026-07-23
- 影响决策：开发基线 D-05

## 背景

开发基线原建议采用“无首次登录墙、保存时再注册”。本阶段最新验收目标明确要求先看到“登录成功”，再进入简单用例生成示例。

## 决策

首个本地验收版本采用登录优先：

1. 未登录时展示本地账号登录/注册页。
2. 注册后自动创建默认质量空间和快速体验用例集。
3. 会话使用 HttpOnly、SameSite=Lax Cookie。
4. 登录后才允许创建持久化生成任务。
5. 验收账号和数据仅用于本地环境。

## 影响

- 当前验收路径更清晰，也能提前验证账号、会话、空间隔离和任务归属。
- 这不是对公开版注册体验的永久冻结。
- D-05 在产品评审时仍需决定：继续登录优先，或恢复“先体验、保存时注册”。
