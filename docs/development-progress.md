## 当前可验收闭环

```text
本地账号注册/登录
→ 创建默认空间与用例集合
→ 输入手机号验证码登录需求
→ API 写入 generation_job
→ Redis 将任务交给 Celery Worker
→ Worker 分 7 阶段发布进度
→ Web 通过 SSE 显示进度
→ 返回风险和 4 条结构化 Pending 用例
→ 进入测试执行并逐条记录本次执行结果
→ 刷新后登录会话保持
```

## 当前边界

- 大模型仍为 Mock，后续通过 Provider Adapter 替换。
- 生成结果当前持久化在 `generation_jobs.output_payload`，尚未拆分写入正式用例与 Revision 表。
- Web 已拆分全局对话首页、空间级用例集管理和单集合工作台；当前使用前端页面状态，下一阶段迁移为正式路由。
- 生成结果已经同步驱动脑图、列表、详情和测试说明；刷新后仍需从正式用例与 Revision 表恢复。
- 首页与集合工作台共享模型选择，`model_id` 已进入生成任务请求；当前 Worker 仍执行 Mock，不代表已经接入真实模型。
- 五种状态已统一为独立视觉语义，详情可切换；当前状态事件仍是前端状态，尚未持久化。
- 测试执行页将“用例状态”和“本次执行结果”分离；步骤确认、实际结果和缺陷引用当前为页面内 Mock 状态，尚未写入 Execution Run/Record。
- 常驻“本地服务已连接”已移除；故障提示将在错误处理里按需出现。
- Docker Compose 是正式本地部署入口；若容器镜像网络不可用，可使用 README 中的本机进程方式。
