## 当前可验收闭环

```text
启动 PostgreSQL、Redis、API 和 Web
→ API 自动创建示例账号
→ 使用 demo@casepilot.local 登录
→ 前端在真实数据库准备 AUTH-001（仅不存在时）
→ 在 AI 工作台选择目标集合并输入测试目标
→ 查看生成阶段、覆盖提醒和候选用例
→ 在脑图/列表与详情之间评审候选内容
→ 主动确认后将候选用例写入正式集合
→ 查看用例集合和结构化用例详情
→ 在列表与脑图之间切换
→ 从集合或模块节点新增用例，从用例节点进入编辑
→ 编辑用例并生成新 Revision
→ 从集合管理页进入 QA 执行页面
→ 或从主导航查看空间内全部执行任务、进度和参与成员
→ 填写任务描述并创建独立执行任务
→ 勾选执行步骤并标记执行状态
→ 填写实际结果和缺陷引用
→ 多位空间成员共同执行，页面自动同步进度
→ 结束任务并以只读方式从任务历史恢复
```

## 当前边界

- 工作台使用本地规则生成候选用例，用于验证完整交互与资产门禁；真实模型
  Provider 和服务端 Generation Job 尚未接入。
- 文件选择只形成当前对话上下文，不上传、不解析文件内容。
- AI 改写当前只记录评审建议，正式修订仍使用结构化用例编辑器完成。
- 当前脑图以 `用例集合 → 模块 → 用例` 组织真实用例数据；节点位置暂不持久化。
- Redis 当前同时服务 API 健康检查和独立 Agent 队列；V0.5 产品界面与 OpenAPI 不提交生成任务。
- 主导航进入空间级任务历史；点击任务进入执行详情，活动任务每 5 秒自动同步。
- 多人协作以空间成员为权限边界；成员邀请与任务级分工仍属于后续范围。
- 执行记录锁定创建该记录时的用例 Revision。用例后续编辑不会篡改历史执行
  内容。
- 用例集合与用例资产无 QA 状态；执行结果绑定到带任务描述的独立 Run。
- 集合和用例删除采用软删除；审计和历史执行数据不会物理删除。
