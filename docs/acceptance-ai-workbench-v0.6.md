# AI 用例工作台验收 V0.6

> 日期：2026-07-27  
> Figma：[AI Workbench V2.2](https://www.figma.com/design/fRnEKJHcshgCIa1CmYXbLx?node-id=38-2)

## 1. 验收范围

- 主导航增加“AI 工作台”，登录后默认进入聊天创建页。
- 创建页支持目标集合选择、测试目标输入、快捷提示和本地附件胶囊。
- 创建页和工作台输入框使用同一个模型选择，支持自动选择、Test Design Pro
  和本地模型；当前选择写入候选用例来源。
- `Enter` 发送，`Shift + Enter` 换行；空输入不允许提交。
- 发送后进入三栏工作区：
  - 左栏：对话、上下文、分阶段进度、覆盖提醒和继续追问；
  - 中栏：用例脑图/列表、候选数量、模块数量和写入操作；
  - 右栏：用例字段、前置条件、步骤/校验点、来源和改写建议。
- 候选用例不会自动进入正式集合；点击“写入用例集”后才调用现有用例创建
  API，并在完成后切换为正式用例数据。
- 已有集合可以跳过生成，直接打开工作台浏览正式用例。
- 用例资产页提供“AI 编辑”入口，可直接在工作台打开当前集合。
- 桌面端左侧对话区和右侧详情区支持拖拽调整宽度，分隔条也支持方向键调整。

## 2. 核心用例

| 编号 | 场景 | 操作 | 预期 |
| --- | --- | --- | --- |
| WB-001 | 首次进入 | 登录系统 | 默认展示聊天创建页和目标集合 |
| WB-002 | 空输入 | 不输入内容查看按钮 | “开始设计”不可用 |
| WB-003 | 快捷提示 | 点击任一示例 | 示例文本进入输入框，可继续编辑 |
| WB-004 | 添加附件 | 选择 Word/PDF/Excel 文件 | 显示文件胶囊，可逐个移除，最多 6 个 |
| WB-005 | 开始设计 | 输入 Audio Feature 目标并发送 | 展示阶段进度，完成后生成结构化候选用例 |
| WB-006 | 视图切换 | 点击脑图/列表页签 | 两个视图读取同一批候选数据 |
| WB-007 | 查看详情 | 点击候选用例 | 右侧展示前置条件、步骤和校验点 |
| WB-008 | 资产门禁 | 生成后不点击写入并切换页面 | 正式集合用例数量不变 |
| WB-009 | 写入集合 | 点击“写入用例集” | 候选通过 API 创建为正式用例并显示成功反馈 |
| WB-010 | 新建对话 | 点击左栏新建对话 | 返回聊天创建页，不删除已保存用例 |
| WB-011 | 打开已有集合 | 创建页点击“打开现有用例工作台” | 直接展示正式用例脑图和详情 |
| WB-012 | 小屏布局 | 缩小到 1080px 以下 | 详情栏隐藏，核心对话与画布仍可操作 |
| WB-013 | 模型选择 | 在创建页选择 Test Design Pro 后发送 | 工作台保持相同模型，候选来源记录该模型 |
| WB-014 | 区域拉伸 | 拖动左右分隔条 | 拖动中只显示预览线，松手后一次性调整宽度；主画布自适应且不触发 ResizeObserver 异常 |
| WB-015 | 集合 AI 编辑 | 在用例资产页点击“AI 编辑” | 直接打开当前集合工作台，不进入空白创建页 |

## 3. 数据边界

- AI 候选不是 QA 执行结果，也不带通过/失败状态。
- 写入正式集合后创建正常 Test Case/Revision；执行结果仍只记录在独立
  Execution Run。
- 当前附件不上传服务端，不读取文件内容。
- 当前候选生成是本地交互实现；真实 Provider、解析和异步任务不在 V0.6
  验收范围。
